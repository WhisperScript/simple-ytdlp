# Security policy

## Supported versions

Only the latest release receives fixes. The app can update itself (**Update now** in the update banner), so please check that you run the newest version first.

## Reporting a vulnerability

Please do not open a public issue. Use **Security -> Report a vulnerability** on this repository's page instead; the report stays private until a fix is out.

Include the version, your operating system and the steps to reproduce. You will get a reply within a few days.
